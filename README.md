# Infinite Scroll Scraper

A Python Selenium project that extracts data from websites using infinite scrolling.

## Features

- Scrolls automatically
- Extracts product names
- Extracts prices
- Saves data into CSV

## Technologies Used

- Python
- Selenium
- Pandas

## Output

infinite_scroll_products.csv
